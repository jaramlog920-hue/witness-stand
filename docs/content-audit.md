  (r021·r022·r023·r024·r028·r029·r030·r050·r052·r057·r058·r078·r079)에 잘못 켜져 있던 것을 끔.
- 판정 설명 문구를 판정이 갈리지 않도록 좁힘.
  - 왜곡: "본문에 있는 말·일을 옮기면서 뜻이 비틀렸다"
  - 거짓: "본문이 말하는 것과 정반대다"
- 삭제된 사건의 기록이 저장소에 남아 있어도 진행도가 부풀지 않도록 집계 방식 수정.
- 등급 최고 구간 90 → 85.

명시한 내용만 담고 있어 삭제·수정 없음.

## 7. 남은 사람의 몫

기계 검증(참조 무결성·인용 일치·근거 범위·중복 답변 규칙)은 `npm run verify`가 매 빌드마다 막아 준다.
판정의 신학적 타당성은 최종적으로 목회자 검토 영역이다. 경계선 사건은 `flags: ["review"]` 로 표시하면
빌드는 통과하되 게시판에 나오지 않는다.
