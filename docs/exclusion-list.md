# 《증언대: 신약 재판소》 콘텐츠 제외 목록

> 이 문서는 모든 사건(소문 사건·증언 사건) 작성·검수의 **최상위 기준**이다.
> 스펙·데이터·화면 문구가 이 문서와 충돌하면 이 문서가 이긴다.

## 0. 한 줄 원칙

**검증 대상은 항상 "사람의 소문·주장"이며, 결론은 항상 "본문이 무엇이라 말하는가"로 끝난다.**
하나님 말씀 자체, 교단 간 견해차, 학자 논쟁은 검증 대상이 아니다.

---

## 1. 절대 제외 — 어떤 형태로도 사건에 넣지 않는다

### 1-1. 핵심 교리를 "의심하는 프레임"에 올리는 것
아래 항목은 소문·주장 형태로도 등장시키지 않는다. "부활은 없다더라 → 판정: 거짓"처럼 결론이 옳더라도, 핵심 교리가 심문대에 오르는 그림 자체가 문제다.
단, **본문이 직접 기록한 소문**(마 28:13 "시체를 훔쳐갔다")은 예외 — 성경이 스스로 반박하는 사례이므로 허용한다. (→ 2-1 참고)

- 예수님의 신성 · 무죄성 · 동정녀 탄생
- 십자가 대속 · 육체 부활 · 승천 · 재림
- 삼위일체
- 성경의 영감·권위
- 구원의 은혜·믿음 원리

### 1-2. 예수님·하나님의 말씀을 판정 대상으로 삼는 것
- "이 말씀은 사실인가?" 형식 금지
- 예수님 말씀은 **근거 구절**로만 등장한다
- 허용: 예수님 말씀을 **왜곡한 제3자의 주장** ("예수가 성전을 헐겠다고 했다" — 거짓 증인의 왜곡, 막 14:58/요 2:19-21)

### 1-3. 교단 간 견해가 갈리는 주제
"성경이 뭐라고 하나"의 답이 정통 교단 사이에서 다른 주제는 사건에서 뺀다.

| 주제 | 이유 |
|---|---|
| 세례 방식(침례/세례), 유아세례 | 교단별 실천 차이 |
| 성찬의 성격(임재·상징·기념) | 교단별 해석 차이 |
| 방언·예언 등 은사의 지속/중단 | 오순절·개혁 교단 차이 |
| 예정·자유의지, 구원의 확실성(견인) | 칼빈/아르미니우스 |
| 여성 안수·직분 | 교단별 실천 차이 |
| 종말론 세부(천년왕국, 휴거 시점, 계시록 상징 해석) | 학파별 차이 |
| 교회 정치(감독제·장로제·회중제) | 교단 구조 차이 |
| 이혼·재혼의 허용 범위 | 목회적 판단 영역 |
| 술·안식일 준수 등 생활 규범의 적용 | 문화·교단 차이 |
| 신유·기적의 현대적 지속 | 교단 차이 |

### 1-4. 학자 간 논쟁이 있는 사실 문제
- 복음서·서신서의 저자·기록 연대
- 사건의 정확한 연대·순서(사복음서 조화 문제)
- 인물 동일성 논쟁(예: 막달라 마리아 = 죄인 여인? 야고보서의 야고보는 누구?)
- 본문 비평(막 16:9-20, 요 7:53-8:11 등 사본 차이)
- 지명·관습의 고고학적 세부

→ 이런 것은 "확인 불가"로도 넣지 않는다. 아예 사건화하지 않는다.

### 1-5. 현대 정치·사회 논쟁으로 직결되는 주제
- 동성애, 낙태, 특정 정당·국가, 이스라엘-팔레스타인
- 본문에 관련 구절이 있어도 게임 소재로 쓰지 않는다

### 1-6. 특정 집단을 조롱·비하하는 프레임
- "유대인들이 퍼뜨린 소문" 같은 집단 일반화 금지 → 본문 표현대로 구체 주체 사용 ("대제사장들과 장로들" 마 28:12)
- 바리새인·사두개인·헬라인·로마인을 희화화하는 삽화·말투 금지
- 소문 게시판의 톤은 "당시 상황 재현"이지 "누군가를 웃음거리로 만드는 것"이 아니다

### 1-7. 외경·전승·교회사 자료
- 도마복음, 야고보 원복음 등 외경 인용 금지
- "전승에 따르면 베드로는 거꾸로 못 박혔다" 같은 교회사 전승은 근거로 쓰지 않는다
- 근거는 **신약 27권 본문(개역한글)** 만 허용. 구약은 신약이 인용한 구절에 한해 보조 근거로 허용.

## 2. 조건부 허용 — 아래 조건을 만족할 때만

### 2-1. 본문이 직접 기록한 거짓 소문·거짓 증언
허용. 성경 스스로 반박하는 구조이므로 오히려 핵심 소재다.
- 마 28:11-15 시체 도난설
- 막 14:55-59 예수 재판의 거짓 증인
- 행 6:11-14 스데반에 대한 거짓 증인
- 행 21:20-28 "바울이 모세를 배반하라 가르친다"
- 살후 2:1-2 "주의 날이 이미 이르렀다"
- 딤후 2:17-18 "부활이 이미 지나갔다"(후메내오·빌레도)
- 갈 1:6-9, 5:2-12 "할례를 받아야 한다"
- 골 2:16-23 절기·천사숭배·금욕 규정
- 고전 15:12 "죽은 자의 부활이 없다"
- 요일 4:1-3 "예수가 육체로 오지 않았다"
- 요 7:12, 7:41-52 "갈릴리에서 선지자가 나느냐"

**조건:** 소문 문구는 본문 표현을 그대로 또는 최소 변형으로 쓰고, 근거 구절이 그 소문을 명시적으로 반박해야 한다.

### 2-2. 본문에 없는 주장 → 판정 "본문에 없음"
"확인 불가"라는 이름은 쓰지 않는다. ("성경도 모른다"로 읽힐 위험)
"본문에 없음"은 **성경이 말하지 않는 부가 정보**에만 쓴다.
- 허용 예: "동방박사는 세 명이었다", "막달라 마리아는 창녀였다", "예수님은 12월 25일에 태어났다"
- 금지 예: 핵심 교리(1-1)에는 절대 이 판정을 붙이지 않는다

### 2-3. 인물의 성격·동기 해석 (증언 사건)
증언 사건에서 "왜 그랬는가"는 **본문이 명시한 동기**만 쓴다.
- 허용: "바리새인들은 안식일에 병 고친 것을 문제 삼았다" (요 9:16 명시)
- 금지: "가룟 유다는 예수님을 억지로 메시아로 만들려 했다" (해석)

### 2-4. 사복음서 병행 기사
같은 사건이 복음서마다 다르게 서술된 부분은 **"모순 찾기"가 아니라 "관점 보충"** 으로만 다룬다.
- 허용: "요한복음에만 나오는 정보는?" 식의 보충 문제
- 금지: "몇 명의 천사가 있었나? 마태 vs 요한" 식의 차이 강조 문제

## 3. 판정 4단계 정의 (제외 기준과 연동)

| 판정 | 정의 | 예 |
|---|---|---|
| **사실** | 본문이 그대로 확인 | "바울은 다메섹 도상에서 회심했다" (행 9) |
| **왜곡** | 본문에 근거가 있으나 의미가 비틀림 | "바울이 율법을 버리라고 가르쳤다" (롬 3:31 반박) |
| **거짓** | 본문이 명시적으로 부정 | "부활은 이미 지나갔다" (딤후 2:18) |
| **본문에 없음** | 성경이 언급하지 않는 부가 정보 | "동방박사는 세 명" |

- "오해"는 "왜곡"에 통합한다. (의도의 유무는 본문이 말하지 않는 경우가 많아 판정 근거가 약함)
- 판정 기준은 **모든 정통 교단이 동의하는 것**만. 한 교단이라도 다르게 볼 여지가 있으면 사건 자체를 삭제한다.

## 4. 화면·문구 제외 규칙

- "이 말씀은 진짜인가?" 류의 문구 금지 → "이 소문은 본문과 맞는가?"
- 판정 결과 화면의 마지막은 항상 **근거 구절 전문**으로 끝난다 (본문이 최종 권위임을 시각적으로 보여줌)
- "가짜뉴스"라는 단어는 게임 내부 UI에서는 쓰지 않고 "소문"으로 통일한다. (외부 소개 문구에서만 사용 가능)
- 재판·심문 비주얼에 예수님을 피고석에 세우는 연출 금지 (예수님 재판 사건은 "거짓 증인"이 검증 대상)
- 예수님 얼굴 묘사 이미지 사용 금지 (전령과 동일 기준)
